### Strengths in learning and project work

- **Connect features to real user flows.** Relate registration, login, and authorization to saving jobs, recording applications, and updating profiles.
- **Pay attention to data ownership.** Identify users from authenticated sessions, check permissions before reading or updating personal data, and separate activity by user_id.
- **Consider consistency.** Investigate repeated save/application actions and conditional JSON updates in S3 using ETags when several sessions are active.
- **Coordinate across responsibilities.** Connect account functionality to the dashboard and work with the administration member to check posting status.
- **Use feedback to improve the product.** Review messages and usage scenarios to make the features easier to follow.

### Areas for improvement

- **Backend and security knowledge.** Study API design, session management, access control, and storage choices for a growing user base.
- **Test design.** Practice integration scenarios, storage failures, concurrent registration, and unauthorized access, while recording actual test results clearly.
- **AWS skills.** Strengthen IAM knowledge, least-privilege application permissions, and service connection troubleshooting.
- **Technical communication.** Describe problems more concisely, with reproduction steps, error messages, and expected results.
- **Progress management.** Break work into smaller tasks and update the journal regularly to record issues and results close to the actual execution time.

### Career direction after the internship

I want to continue in **Backend / Cloud**, strengthening Python programming, API design, databases, and user features with explicit access controls. I will also continue studying application deployment, monitoring, and management on AWS.

For Vietnam IT Job Market, I want to explore account and user data design more deeply, improve testing skills, and write clearer technical documentation. These are skills I need to develop for future backend and cloud projects.
