I am **Hà Mạnh Cường**, a student in class **K68CNTTC**, majoring in **Information Technology** at **Vietnam National University of Agriculture**. I interned at **Amazon Web Services** from **08/08/2026 to 31/10/2026**. In **Vietnam IT Job Market**, I was responsible for **Authentication & User**, focusing on accounts, authorization, and personal user features.

The following reflections are written from the perspective of a student strengthening programming and cloud knowledge with a **Backend / Cloud** career direction.

### Assessment by aspect

**1. Learning environment**

Combining AWS self-study with a project helped me connect knowledge to a concrete application. Building account functionality required me to consider the interface, business logic, access permissions, and stored data together. This approach helped me understand what is required for a feature to work within a system.

**2. Documentation and support**

Project documentation and source code helped me trace processing flows and investigate problems. Effective technical discussion requires clear steps, error messages, and expected results. In addition to finding a solution, I need to understand the cause so that I can handle similar situations independently.

**3. Relevance to Information Technology**

Authentication & User connects programming, databases, web applications, and security. Registration, login, saved jobs, application records, and profile updates in Vietnam IT Job Market must all be associated with the user's identity. This provides a foundation for further study of backend design and AWS application deployment.

**4. Skills developed**

- Read and trace flows from the interface through services to storage.
- Identify access permissions and the data belonging to each user.
- Consider invalid input, repeated actions, and S3 read/write errors.
- Coordinate with dashboard, data, and administration members.
- Organize notes, describe features, and prepare test scenarios.

**5. Community culture**

Activities such as **Mini Meetup – First Cloud AI Journey on 17/10/2026** provided learning opportunities alongside project work. As a newcomer, I can participate by listening, asking specific questions, and sharing problems within my understanding. I want to maintain that willingness to learn in future activities.

**6. Practice environment**

Working with accounts and user data requires attention to credentials, read/write permissions, and the effect of each action. A practice environment should include test accounts, sample data, and explicit verification criteria. Recording execution conditions and results helps distinguish functionality present in the code from functionality verified in the deployment environment.

### Feedback questions

**What was most satisfying?**

I valued the opportunity to connect what I learned to work with clear user flows. Saving a job requires identifying the account, checking posting status, and storing data for the correct user. Seeing these connections helped me understand backend responsibilities in an application.

**What was the greatest difficulty?**

I need to improve handling scenarios beyond the normal successful workflow. Besides successful login or storage, I must consider incorrect input, insufficient permissions, connection failures, and concurrent updates. I need more practice breaking problems down, designing tests, and recording results for systematic troubleshooting.

**What should the program improve?**

- Add pre-lab checklists covering prerequisite knowledge, access permissions, and expected outcomes.
- Provide more IAM, S3, and application connectivity troubleshooting examples with a clear investigation sequence.
- Include practical scenarios for session management, permission checks, and protecting private web application data.
- Schedule short progress discussions so learners can receive feedback before compiling the final report.

**Would I recommend the program to friends?**

I would recommend it to friends interested in AWS who are willing to spend time studying and practicing independently. I would also emphasize proactive reading, resource monitoring, and recording results to make learning effective.

### Additional suggestions

- **Share work by team responsibility.** Each member can explain their flow, from pipelines and analytics to interfaces, accounts, and administration. This helps the team understand integration points.
- **Practice failure scenarios.** Add exercises with sample data for duplicate email registration, unauthorized access, storage failures, and concurrent updates.
- **Standardize evidence records.** Each result should include its time, environment, and relevant version information so others can verify it.
- **Allow more design discussion.** Explaining storage choices, session management, and permission checks helps learners understand the system instead of only following steps.

**Would I like to remain involved in the program?**

With a **Backend / Cloud** direction, I want to continue learning AWS and participate in suitable knowledge-sharing activities. I plan to strengthen Python, API design, databases, application security, and deployment skills. Within Vietnam IT Job Market, accounts and user data are areas I can continue exploring to develop these skills.

### Acknowledgments

I thank **First Cloud AI Journey**, the mentors, and the **AWS Study Group** community for the learning resources and opportunities to exchange knowledge. I also thank the Vietnam IT Job Market team for their cooperation. The internship helped me reflect on my current knowledge, identify areas for improvement, and continue pursuing Backend / Cloud.
